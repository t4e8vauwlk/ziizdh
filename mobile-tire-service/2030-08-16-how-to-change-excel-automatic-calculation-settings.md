By default, Excel will automatically calculate any formulas you put in your worksheet. In this article, we'll teach you how to change auto-calculation globally (in the desktop version) or sheet-by-sheet (in the desktop and web versions of Excel). These steps work on both Windows and Mac computers. Keep reading to learn how. Changing Excel Auto-Calculation

To change auto-calculation in Excel for desktop or web on a sheet-by-sheet basis, click on the Formulas tab. Under "Calculation Options," choose Automatic, Partial, or Manual. You can change the global auto-calculation in desktop Excel by going to File > Options > Formulas. Steps Method 1 Method 1 of 3: Changing Global Auto-Calculation 1

Open Excel and click File > Options. If you don't have an Excel document open, you can skip clicking the File button, as you'll be on this menu by default when opening Excel.

This method will change the auto-calculation settings for every sheet you make. If you only want to change the auto-calculation settings for just one sheet, jump to our sheet auto-calculation method below. 2

Click Formulas. It's in the left-hand sidebar, near the top of the list. Advertisement 3

Choose how you want Excel to handle auto-calculation. There are three options:

Automatic: Automatic means that Excel will auto-calculate everything in the document as soon as something is changed.

Partial: If "partial" is selected, Excel will calculate everything automatically except cells that are in data tables.[1]XResearch source

In previous versions of Excel, this was called "Automatic Except for Data Tables." Partial functions in the same way as this setting did.

Manual: This option turns off auto-calculations in Excel, so you'll have to calculate everything on your own.[2]XResearch source

If you choose Manual, the "Recalculate workbook before saving" option will be automatically selected. If you don't want Excel to recalculate the workbook before saving, uncheck this option.

Partial and Manual are great options if you have a huge workbook that lags out when you try to update or view it. 4

Click OK to save your options. If you chose either Partial or Manual, you can click on the Formulas tab in Excel and click Calculate Now (for all open worksheets) or Calculate Sheet (for the currently open worksheet) to manually recalculate them.[3]XTrustworthy SourceMicrosoft SupportTechnical support and product information from Microsoft.Go to source Advertisement Method 2 Method 2 of 3: Changing Sheet Auto-Calculation 1

Open your document and click the Formulas tab. You'll see this in the editing ribbon above the document space.

This method changes the auto-calculation settings for a single sheet. If you want to change your overall auto-calculation settings, go back up to our global auto-calculation method above. 2

Click Calculation Options. You'll see this under the icon of a calculator in the "Calculation" group. 3

Select a calculation rule. You can choose:

Automatic: Automatic is the default option that tells Excel to refresh the calculation any time information in the formula's data range is edited.

Partial: If "partial" is selected, Excel will calculate everything automatically except cells that are in data tables.

In previous versions of Excel, this was called "Automatic Except for Data Tables." Partial functions in the same way as this setting did.

Manual: This option turns off auto-calculations in Excel, so you'll have to calculate everything on your own.

If you chose either Partial or Manual, you can click on the Formulas tab in Excel and click Calculate Now (for all open worksheets) or Calculate Sheet (for the currently open worksheet) to manually recalculate them.

Partial and Manual are great options if you have a huge workbook that lags out when you try to update or view it. Advertisement Method 3 Method 3 of 3: Changing Auto-Calculation in Web Excel 1

Open your spreadsheet and click the Formulas tab. It's at the top of the screen, near the middle of the ribbon.

Note that if you use web Excel, you can only change auto-calculation settings on a sheet-by-sheet basis. 2

Locate the "Calculation Options" dropdown. By default, Automatic will be chosen. 3

Click the dropdown and choose your desired calculation type. The calculation types are as follows:

Automatic: Automatic means that Excel will auto-calculate everything in the document as soon as something is changed.

Automatic Except for Data Tables: If this option is selected, Excel will calculate everything automatically except cells that are in data tables.

Manual: This option turns off auto-calculations in Excel, so you'll have to calculate everything on your own.

If you chose either Automatic Except for Data Tables or Manual, you can click on the Formulas tab and click Calculate Workbook (for all sheets in the open workbook) or Calculate Sheet (for the currently open sheet) to manually recalculate them.[4]XTrustworthy SourceMicrosoft SupportTechnical support and product information from Microsoft.Go to source
